# Incident Management System

A portfolio-oriented technical incident management system built while completing an Angular 20 training challenge.

## Current Status

The Angular 20 frontend has been initialized and verified locally.

The Spring Boot backend and MySQL database are planned for later stages.

## Technology Stack

- Angular 20
- TypeScript with strict mode
- SCSS
- Spring Boot 3 (planned)
- MySQL (planned)
- Git and GitHub

## Project Structure

```text
incident-management/
├── frontend/    # Angular application
├── backend/     # Future Spring Boot application
├── docs/        # Project documentation
└── .github/     # GitHub Copilot instructions
```

## Prerequisites

- Node.js 20.19.0 or newer.
- npm.
- Git.

## Run the Frontend

```bash
cd frontend
npm install
npm start
```

Open `http://localhost:4200` in a browser.

## Run a Production Build

```bash
cd frontend
npm run build
```

## Documentation

- `docs/AI_CONTEXT.md`: Persistent project context for AI-assisted work.
- `docs/ARCHITECTURE.md`: High-level system architecture.
- `docs/ROADMAP.md`: Training challenge progress.
